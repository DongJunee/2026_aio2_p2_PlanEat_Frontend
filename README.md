# PlanEat Frontend

Streamlit 기반 냉장고 사진 챗봇 UI 프로토타입입니다. 백엔드 API는 호출하지 않습니다.

## 실행

```powershell
cd C:\PlayEat\FrontEnd
uv sync
uv run streamlit run streamlit_app.py
```

기존 가상환경을 사용하면 `.\.venv\Scripts\python.exe -m streamlit run streamlit_app.py`로도 실행할 수 있습니다.

## 데모 흐름

1. 입력창의 + 버튼으로 사진을 첨부하거나 ‘예시 냉장고로 시작하기’를 선택합니다.
2. 재료 표에서 이름·수량을 수정하고, 행을 추가·삭제한 뒤 확정합니다.
3. 사이드바에서 식사 조건을 입력하고 ‘내 한 끼 5세트 보기’를 선택합니다.
4. 세트 상세, 부족 재료의 중요도, 장보기 목록과 다운로드를 확인합니다.
5. ‘재료 다시 수정’ 또는 ‘새로운 대화’로 돌아갈 수 있습니다.

## 첨부 및 데모 범위

- Streamlit 기본 채팅 입력창의 다중 이미지 첨부와 전송 전 미리보기·삭제를 사용합니다.
- 한 번에 최대 5장, JPG/PNG/WEBP, 장당 10MB입니다. 6장 이상 전송하면 요청 전체를 거절하고 다시 선택하도록 안내합니다.
- 실제 이미지 분석 대신 고정 예시 재료를 표시합니다. 이미지 붙여넣기와 OS 카메라 촬영은 별도 구현하지 않았습니다.
- 추천 5세트는 고정 예시이며 목적·시간·알레르기·채식·자연어 조건은 실제 추천에 적용되지 않습니다.
- 레시피·분량·영양·조리 순서는 공식 DB 데이터가 아닌 UI 예시입니다. 실제 레시피 사진 대신 아이콘을 표시합니다.
- 보유·부족 재료는 사용자가 확정한 재료 이름을 기준으로 비교합니다. 수량 계산과 동의어 매칭은 미구현입니다.
- 사진과 대화는 현재 세션에서 사용하며 별도 파일이나 DB로 저장하지 않습니다.

## 백엔드 연결 위치

`streamlit_app.py`의 TODO 주석에 이미지 추출, 확정 재료와 조건 전달, 자연어 요청, 원본 레시피 상세 조회 연결 위치를 표시했습니다.
